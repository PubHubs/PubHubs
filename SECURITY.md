# Security policy

## Reporting a vulnerability

Please don't report security problems in a public issue. Report them privately on GitHub instead, through [Report a vulnerability](https://github.com/PubHubs/PubHubs/security/advisories/new) in this repository's Security tab. Only the PubHubs maintainers see what you send there.

It helps if you tell us:

- which part is affected: PubHubs Central, the global client, a hub server, a hub client or the app;
- how to reproduce it, and on which version;
- what an attacker could do with it.

We'll confirm that we got your report, keep you posted while we work on a fix, and credit you in the advisory if you'd like.

## Supported versions

Security fixes go into the latest release only.

## Other projects

PubHubs builds on [Yivi](https://yivi.app) and [Matrix Synapse](https://github.com/element-hq/synapse). If the problem lies in one of those, please report it to that project.
