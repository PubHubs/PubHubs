# Contributing

Thanks for wanting to help with PubHubs.

The PubHubs team works on
[Radboud University's GitLab](https://gitlab.science.ru.nl/ilab/pubhubs_canonical). Our
[GitHub repository](https://github.com/PubHubs/PubHubs) is a mirror of it, so pull requests on GitHub
can't be merged there.

If you would like to contribute code or documentation, please
[contact the team](https://www.pubhubs.net/en/help/contact/) first. We can then talk about what you
have in mind and how to get it into PubHubs.

Found a bug, or have an idea? You can [open an issue](https://github.com/PubHubs/PubHubs/issues) on
GitHub without asking first. Security problems go privately, as described in the
[security policy](SECURITY.md).

To find your way around the code, see [Development](docs/development.md) and the
[coding guidelines](docs/coding-guidelines.md).
